# Мальований космонавт: джерела й статичні текстури

Спочатку прочитай кореневий `AGENTS.md`, roadmap і локальний `README.md`.

- `source/` — незмінні оригінали; не перезаписуй їх при нормалізації чи експорті.
- Основний front — `source/front.svg` («перед (2)»); альтернативний зберігаємо окремо.
- Розміри, SHA-256 і затверджені ракурси описано в `source-manifest.json`.
- Статус оригіналів — `raw-source`; для етапу 1 окремо згенеровано чотири
  прозорі статичні текстури в `public/assets/astronaut/`. Це ще не анімації.
- Не видаляй білі частини скафандра разом із фоном. Не дзеркаль малюнки замість
  наданих лівого та правого ракурсів без погодження.
- Персонаж у грі — мальований 2D-спрайт; світ — 3D, камера фіксована ізометрична.
- Статичні пози не називай готовими анімаційними циклами. Не вигадуй відсутні кадри.
- Генератор — `scripts/astronaut/prepare.mjs`, геометрія — сусідній
  `svg-geometry.mjs`. Підготовлені SVG та маніфест не редагуй вручну.
- Генератор перевіряє SHA-256 оригіналу, видаляє лише один перевірений суцільний
  фоновий path з індексом 0 і зберігає решту path без зміни. Новий формат джерела
  або додатковий фоновий path потребує перевірки, а не послаблення захисту.
- Спільне полотно — 1024×1024, видима висота — 840 px, опора — (0.5, 0.92).
  Масштаб рівномірний, межі розраховані за екстремумами кубічних кривих.
- `idle` і `move` поки посилаються на один статичний кадр кожного напрямку:
  `fps: 0`, `staticPose: true`, `animationReady: false`. Не імітуй готовий біг
  простим повторенням цього кадру чи рухом усієї картинки.
- Наступне завдання графіки: етап 3 — підготувати шари або справжні додаткові
  кадри idle/руху/дій, зберігши затверджені ракурси та спільну точку опори.
- Після зміни запусти команди з README, перевір прозорість і перекриття у браузері
  та онови поточний стан і журнал за кореневим протоколом передачі роботи.
