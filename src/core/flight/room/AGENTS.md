# Навчальна кімната етапу 1

Спочатку кореневі AGENTS, ROADMAP, ARCHITECTURE й контракти.

- Це ізольований generic Phase із RoomResult; не підмінюй ним FlightResult або
  підключений політ Максима без адаптера й перевірок етапу 2.
- Світ: метри XZ, дані — `src/data/flight-room.json`. UI використовує той самий
  blueprint для геометрії; не дублюй координати пульта чи межі зіткнень.
- Камера не впливає на фізику. UI передає вектор світу та напрямок малюнка;
  ядро нормалізує швидкість, обмежує dt й перевіряє зіткнення підкроками.
- Просте завдання використовує наявний computeSolarPowerEfficiency. Закритий
  пульт не приймає команди, скасування не завершує завдання, успіх зупиняє фазу.
- `flight:room:N` має бути унікальним щодо вхідного журналу; невдала команда
  посилається на конкретне рішення. finish повертає лише нові записи.
- Додаткові ресурси, таймери, інерція й повні мініігри — наступні узгоджені зміни.
- Зберігай JSON, чистоту, детермінізм і тести руху, взаємодії та причин.
