# Вимоги до спрайтів

Спрайти — намальовані об'єкти гри: апарат, його модулі, оператор, станція. У сцені вони стоять як площини, завжди повернуті до камери. Поки файла немає, гра показує заглушку (кольоровий прямокутник із підписом id), тож малювати можна в будь-якому порядку.

## Файл

- PNG із прозорим тлом, довша сторона 512 px.
- Назва файла дорівнює id: `cam-m.png`, `bus.png`. Список id і теки дивись у `src/data/sprites.json`.
- Класти в `public/assets/sprites/<тека>/`: `modules/`, `spacecraft/`, `world/`, `crew/`.

## Вигляд

- Ракурс: вигляд спереду трохи згори. Камера в грі нерухома, тож усі спрайти малюються під один ракурс.
- Світло зліва згори.
- Темний контур 4–6 px кольору `outline`.
- Кольори лише з палітри `src/render/palette.ts`:

| Назва | Колір | Для чого |
|---|---|---|
| `hull` | `#c9ced9` | корпус |
| `panel` | `#2f4f8f` | сонячні панелі |
| `metal` | `#7d8597` | метал, кріплення |
| `outline` | `#10131f` | контур |
| `accent` | `#a7e8d3` | активне, промінь зв'язку |
| `alarm` | `#ff5d5d` | відмова |
| `calm` | `#6fcf97` | норма |
| `storm` | `#f4b46a` | буря |

Тінь і тривогу на спрайт не малюй: сцена сама затемнює апарат у тіні й підфарбовує його під час відмови.

## Розмір і точка прив'язки

Розмір у грі задається не пікселями, а полем `widthUnits` у `src/data/sprites.json` (ширина у світових одиницях; висота береться з пропорцій картинки). `anchor` — точка, якою спрайт кріпиться: `[0.5, 0]` середина нижнього краю, `[0.5, 0.5]` центр, `[1, 0.5]` середина правого краю. Якщо модуль стоїть криво, правимо ці два числа, а не картинку.

## Як перевірити

`npm run dev`, відкрити `#gallery`. Щойно файл лежить у теці, він замінює заглушку після перезавантаження сторінки.

`spriteSource` бере список наявних PNG через Vite з `sprite-files.ts`; цей модуль завантажується лише при створенні спрайтів. Якщо запис є в маніфесті, а файла ще немає, сцена зберігає розмір і точку прив'язки заглушки та не робить запиту до PNG. Так відсутні малюнки не засмічують консоль помилками 404. Якщо сам список не завантажився, заглушки теж лишаються видимими.
