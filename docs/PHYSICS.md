## 2. Заміна двох умовних моделей

### 2.1 `lifetimeOrbits(altKm)`: скільки витків живе апарат

Зараз: `((alt − 150)/50)²`, мінімум 1. Дає 25 витків на 400 км і 49 на 500 км, тобто менше доби. Реально на 400 км малий супутник живе **роки**:

| Висота, км | Наша модель, витків | Джерело A (3U, BC 175 кг/м²), роки | Джерело B (6U, BC 72 кг/м², середній цикл), роки |
|---|---|---|---|
| 400 | 25 | 1,2 | |
| 450 | 36 | | 1,8 |
| 480 | 43 | | 3,2 |
| 500 | 49 | 6,3 | |
| 600 | 81 | 23,5 | 24,9 |
| 700 | 121 | понад 25 | |

Джерело A: arXiv 1901.11121 (Table, 3U CubeSat). Джерело B: arXiv 2609.24534 (FACSAT-2, таблиця за висотою ін'єкції; для сонячного максимуму значення в 2–3 рази менші, для слабкого циклу в 2 рази більші).

**Пропонована формула** (для Іллі):

```
life_years(h, BC) = 1,8 · exp((h − 450)/57) · (BC / 72)
life_orbits       = life_years · 31 557 600 с / periodS(h)
```

Означення: `h` висота, км; `BC = m/(Cd·A)` балістичний коефіцієнт, кг/м²; `periodS` з `orbitalPeriodS`. Постійні 1,8 року і 57 км підігнані під джерело B (середній цикл); масштаб висоти 55–75 км узгоджується з обома джерелами (A: 52–60 км на 100 км, B: 52–59 км). Лінійність по BC стандартна: швидкість спаду пропорційна ρ/BC.

Що дає формула (BC = 72): 300 км 0,13 року (≈ 750 витків, «тижні»), 400 км 0,75 року (≈ 4300 витків), 500 км 4,3 року, 600 км ≈ 25 років. Для BC = 175 (як у джерелі A) усе ≈ ×2,4.

**Точність і межі.** Похибка в 2–3 рази через сонячну активність; джерела A і B на 600 км збігаються лише завдяки різному BC, тож це оцінка порядку величини. Нижче ≈ 200 км формулу не екстраполювати: там густина росте швидше, апарат живе години-дні, лишити мінімум 1 виток. BC апарата в грі можна брати сталим (≈ 72) або з маси та перерізу.

**Наслідок для гри.** Місія триває `durationOrbits = 10` (≈ 15 годин). З реальною моделлю життя на висотах ≥ 300 км на кілька порядків більше за місію, тож `lifetimeOrbits` не буде обмеженням у звичайній місії; він матиме значення лише для дуже низьких орбіт, для довших місій або для наслідків відмови (апарат без палива падає не одразу). Це рішення для команди, не для фізики.

### 2.2 `reachedAltKm`: на яку висоту вистачає палива

Зараз: якщо Δv ≥ потрібного, апарат на заданій висоті; інакше лінійно між `0,5·altMin` і заданою. Лінійність за Δv не має фізичного сенсу. Правдоподібна модель: висота, на яку піднімає наявне Δv, з Гомана між колами (формули з `vis-viva`, `r = R + h`):

```
v(r)     = √(μ/r)
Δv(h1→h2) = [√(μ(2/r1 − 1/a)) − v(r1)] + [v(r2) − √(μ(2/r2 − 1/a))],  a = (r1 + r2)/2
reachedAlt = найбільше h2, для якого Δv(h_старт → h2) ≤ spec.dvMs   (знайти бісекцією)
```

Потрібна стартова висота (висота ін'єкції носія): в `missions.json` її немає; для запропонованої моделі її треба додати в місію або задати константою. Контрольні числа (Гоман, R = 6371 км, μ = 398 600): 400→500 км 56 м/с; 400→800 км 217 м/с; 500→800 км 161 м/с; 300→800 км 274 м/с. Тобто вимога `dvRequiredMs = 300` для місії 400–800 км реалістична і з запасом; для порівняння, SkySat має загальне Δv 180 м/с.

Важливо: це Δv для **хімічних** двигунів. Для іонного спіраль замість Гомана потребує Δv ≈ v1 − v2 (для 400→800 км 217 м/с, майже те саме), але займає тижні (розділ 4, п. 1).

Закриває розбіжність D8: нестача Δv дає апарат на проміжній висоті, а не «0,5 від мінімуму».

## 4. Нефізичне

1. **Іонний двигун не споживає електрику й дає Δv миттєво.** Реально електричний двигун має тягу 0,1–20 мН. Приклад: апарат 100 кг, Δv 300 м/с, тяга 5 мН: ≈ 70 діб безперервної роботи (1 мН: ≈ 350 діб, 20 мН: ≈ 17 діб). Потрібні потужність (від десятків до сотень Вт) і час маневру. Це міняє баланс «іонний проти хімічного»: іонний дешевший за паливом, але дорогий за енергією й часом.
2. **`eng-cold` з Isp 220 с.** Cold gas реально 40–110 с. 220 с це гідразин. Або перейменувати модуль, або знизити Isp до ≈ 70–110 с.
3. **Батареї втричі-вдесятеро надто важкі за Вт·год.** 120 Вт·год це ≈ 0,5–0,8 кг елементів, а не 12 кг. Через це «кожен ват·год коштує маси» і запас енергії штучно дорогий.
4. **Передавачі й антени ×5–20 по масі.** Реальне радіо 0,02–0,75 кг.
5. **`lifetimeOrbits` занижений у сотні разів** (розділ 2.1); `reachedAltKm` лінійний (розділ 2.2).
6. **Тінь завжди 35 хв за виток.** Це найгірший випадок (β = 0), у грі її варто пояснити гравцеві.
7. **Зв'язок кожен виток по 480 с.** Реально пролітів на добу кілька, не кожен виток.
8. **`durationOrbits = 10` (≈ 15 годин).** Реальні місії тривають місяці й роки; для життя апарата і дрейфу висоти це суттєво.
9. **Масу конструкції, обігрів і базове споживання (`STRUCTURE_MASS_KG` 40 кг, `BASE_LOAD_W` 20 Вт, `HEATER_W` 15 Вт, `BUFFER_MB`) зі зібраних джерел перевірити не вдалось.** Це ігрові сталі.
