# Технічне завдання (ТЗ) для 2D-дизайнера — проєкт `hryah`

## 1. Головний принцип (як це працює)

1. **На виході від дизайнера потрібен лише один `.zip`-архів з `.svg` файлами**, названими строго за списком нижче.
2. **Розміри, масштабування та координати підганяє сама програма.** Не потрібно вираховувати пікселі під екрани — достатньо малювати кожен елемент на зручному квадратному чи прямокутному артборді (наприклад, `256×256` або `512×512`) по центру з прозорим фоном.
3. **Єдині дві технічні вимоги при експорті SVG з Figma / Illustrator:**
   - Галочка **Outline Text / Convert to Outlines** (щоб шрифти не злітали).
   - Збережений `viewBox` (стандартний експорт Figma робить це автоматично).
4. **Ми не малюємо зайвого:** фони космосу, зірки, сітки радарів, графіки, кнопки UI, прапори країн та карти планет **дизайнеру малювати НЕ треба** — частину вже малює код, а частину ми беремо з безкоштовних відкритих бібліотек (NASA / Wikimedia / Kenney CC0 / Lucide Icons).

## 2. Що малює дизайнер (по фазах гри)

Загальний обсяг на всю гру — **23 базові концепти** (разом із варіаціями S/M/L для модулів супутника — **33 `.svg` файли**).

---

### Фаза 1: Конструктор супутника (`design`)

Гравець збирає супутник із корпусу та 5 модулів. Програма сама складає ці SVG у єдиний корабель на екрані.

> **Лайфхак для економії часу:** для модулів `S / M / L` не треба малювати три принципово різних об'єкти. Достатньо намалювати один базовий модуль і зробити йому 3 градації (наприклад, у `sol-s` — 2 секції сонячної панелі, у `sol-m` — 4 секції, у `sol-l` — 6 секцій).

#### 1.1. Корпус та ракети-носії (4 файли)
| Назва файлу в архіві | Що зображено |
| :--- | :--- |
| `bus-standard.svg` | Центральний корпус супутника (металевий куб/циліндр у стилі CubeSat / SmallSat із золотистою термофольгою). |
| `launcher-small.svg` | Легка ракета-носій (1 ступінь, компактна). |
| `launcher-medium.svg` | Середня ракета-носій (класична двоступенева ракета типу Falcon 9). |
| `launcher-heavy.svg` | Важка ракета-носій (центральний блок + 2 бічні прискорювачі з боків). |

#### 1.2. Модулі супутника — 5 категорій по 3 рівні S/M/L (15 файлів)
| Категорія | Назви файлів в архіві | Що зображено |
| :--- | :--- | :--- |
| **Двигуни** | `eng-cold.svg`<br>`eng-chem.svg`<br>`eng-ion.svg` | 1. Маневрове газове сопло (сіро-блакитне).<br>2. Хімічний ракетний двигун із розтрубом (помаранчевий акцент).<br>3. Іонний двигун із блакитним кільцем світіння. |
| **Сонячні панелі** | `sol-s.svg`<br>`sol-m.svg`<br>`sol-l.svg` | Крила сонячних батарей (сині фотоелементи з сіткою): малі (2 секції), середні (4 секції), великі (6 секцій із золотистими кріпленнями). |
| **Акумулятори** | `bat-s.svg`<br>`bat-m.svg`<br>`bat-l.svg` | Блок батарей (зелено-бірюзовий індустріальний корпус): на 1, 2 та 3 енергетичні комірки. |
| **Антени зв'язку** | `ant-s.svg`<br>`ant-m.svg`<br>`ant-l.svg` | 1. Проста штирьова антена (`ant-s`).<br>2. Плоска фазована решітка (`ant-m`).<br>3. Кругла параболічна тарілка (`ant-l`). |
| **Наукові камери** | `cam-s.svg`<br>`cam-m.svg`<br>`cam-l.svg` | 1. Компактна камера з малим об'єктивом (`cam-s`).<br>2. Подвійний мультиспектральний сканер (`cam-m`).<br>3. Довгий тубус орбітального телескопа з великою лінзою (`cam-l`). |

### Фаза 2: Політ і виживання на станції (`flight`)

Вид зверху (2.5D top-down). Космонавт літає в невагомості всередині відсіків станції, відштовхуючись від поручнів, і лагодить термінали.

#### 2.1. Анімований спрайт космонавта (4 файли — ключові пози одного персонажа)
Це **один і той самий персонаж** (вид зверху/3/4, у білому скафандрі з ранцем та синім візором шолома, дивиться вправо `>`), намальований у 4 простих станах, які програма сама перемикає:

| Назва файлу в архіві | Стан / поза |
| :--- | :--- |
| `astro-idle.svg` | Спокійно тримається руками за поручень (базова поза). |
| `astro-pull.svg` | Згрупувався, підігнув ноги перед відштовхуванням (натягування рогатки). |
| `astro-fly.svg` | Летить у невагомості: тіло витягнуте, руки вперед. |
| `astro-stun.svg` | Зіткнувся зі стіною (розведені руки/ноги, тріщина або червоний блік на візорі). |

#### 2.2. Інтер'єр космічної станції (8 файлів)
Стіни, підсвітку тривоги та ілюмінатори рендерить сама гра, але щоб станція виглядала живою, потрібні шаблони відсіків та об'єктів усередині:

| Назва файлу в архіві | Що зображено |
| :--- | :--- |
| `mod-horizontal.svg` | Текстура/шаблон підлоги горизонтального відсіку (восьмикутник зі зрізаними кутами, металеві плити, решітка вентиляції). Використовується для Енергоблоку та Термовідсіку. |
| `mod-hub.svg` | Шаблон підлоги центрального вузлового хабу (рівносторонній восьмикутник із круглим люком по центру). Використовується для Хабу та Командного містка. |
| `mod-vertical.svg` | Шаблон підлоги вертикальної лабораторної шахти (витягнутий по вертикалі восьмикутник). |
| `console-terminal.svg` | Настінна комп'ютерна стійка/пульт із монітором (програма сама міняє колір екрана й домальовує антену/труби/тарілку). |
| `handle-rail.svg` | Металевий поручень-ручка на двох кронштейнах (космонавт чіпляється за нього). |
| `door-seal.svg` | Масивні стулки закритого гермошлюзу між відсіками (в оранжево-чорну смужку). |
| `obstacle-pillar.svg` | Кругла техногенна колона/генератор (вид зверху, стоїть посеред відсіку, від неї рикошетить космонавт). |
| `obstacle-cargo.svg` | Квадратний космічний вантажний ящик/контейнер зі стяжними ременями (вид зверху). |

### Фаза 3: Орбітальне сканування (`orbit`)

На цьому етапі наш зібраний супутник (з темплейтів Фази 1!) летить над планетою і сканує цілі. Тому майже всі темплейти сюди автоматично переходять із Фази 1. Домалювати потрібно лише 2 маленькі елементи:

| Назва файлу в архіві | Що зображено |
| :--- | :--- |
| `ground-station.svg` | Наземна станція зв'язку (біла купольна/тарілкова антена на землі для скидання даних). |
| `target-poi.svg` | Значок точки інтересу / цілі сканування на поверхні планети (прицільна мітка/пін). |

## 3. Що дизайнеру малювати НЕ ТРЕБА (вже завантажено з вільного доступу або генерує код)

Щоб не перевантажувати дизайнера рутиною, ці елементи вже закриті в репозиторії:

1. **Карти та зображення Землі і Місяця (`public/assets/bodies/`)** — вже завантажені векторні SVG (`earth-map.svg` із Wikimedia Commons CC0, `earth-globe.svg` і `moon.svg` із Google Noto Emoji Apache 2.0), а в `OrbitScene.tsx` також є процедурний векторний рендер Землі.
2. **Емблеми 4 вигаданих агенцій консорціуму (`public/assets/icons/agencies/`)** — уже завантажені SVG-герби (`borealis.svg`, `monsoon.svg`, `meridia.svg`, `kestrel.svg`) з Game-Icons.net (CC BY 3.0). Реальні прапори країн у грі не використовуються.
3. **27 дрібних іконок UI (`public/assets/icons/ui/`) та 4 технічні іконки СЖЗ/радара (`public/assets/icons/station/`)** — уже завантажені з Lucide Icons (ISC) та Game-Icons.net (CC BY 3.0). Деталі ліцензій записані в `public/assets/ATTRIBUTION.md`.
4. **Екрани мініігор (Стикування, Сонячні панелі, Життєзабезпечення)** — усі приціли, синусоїди, радари, тумблери та шкали тиску вже повністю намальовані програмно на Canvas.
